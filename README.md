- Python 3.10 o superior recomendado.
- Windows, Linux o macOS con Tkinter disponible.

# Sistema de Autómatas Finitos y Regex Lab

## Funcionalidades principales

* **Creación de autómatas:** permite definir estados, alfabeto, estado inicial, estados finales y transiciones.
* **Simulación de autómatas:** permite comprobar si una cadena es aceptada o rechazada.
* **Conversión de AFN a AFD:** transforma un autómata no determinista en uno determinista.
* **Minimización de AFD:** permite reducir estados equivalentes del autómata determinista.
* **Análisis de expresiones regulares:** permite validar cadenas mediante patrones definidos con expresiones regulares.
* **Búsqueda de coincidencias:** permite identificar coincidencias dentro de cadenas de texto.
* **Generación de autómatas:** permite trabajar con la conversión de expresiones regulares a autómatas.
* **Centro de registros:** almacena y permite consultar eventos relacionados con el funcionamiento de la aplicación.

**Instalación y ejecución**
Descargar la aplicación SistemaAutómatas.exe y en la ventana que aparece darle clic en ejecutar y listo la aplicación se iniciará.

**Organización del proyecto**

El sistema se encuentra organizado en módulos que separan las funcionalidades principales de la aplicación.

Entre los módulos del proyecto se contemplan:

Interfaz gráfica: permite la interacción del usuario con el sistema.

Módulo de autómatas: administra la estructura y operaciones de los autómatas finitos.

Módulo de expresiones regulares: procesa y valida patrones y cadenas.

Módulo de conversión: realiza los procesos de transformación entre representaciones.

Módulo de minimización: aplica el proceso de reducción de estados.

Base de datos: administra el almacenamiento de los registros.

Gestor de registros: facilita la consulta y exportación de eventos.

La distribución exacta de los archivos puede consultarse directamente en el repositorio.
